# 知识库使用手册

## 一、本地写作

1. 安装 [Obsidian](https://obsidian.md)
2. `Open folder as vault` → 选本仓库的 `content/` 目录
3. 建议开启插件：**Templater**（用 `{{date}}`）、**Dataview**（可选）

## 二、Frontmatter 规范

```yaml
---
title: 笔记标题        # 必填
date: 2026-10-23       # 创建日期
tags: [科技, AI]       # 标签，用于标签页聚合
maturity: seedling     # seedling / budding / evergreen
description: 一句话摘要  # 出现在搜索与列表页
draft: false           # true 则不会发布到站点
---
```

## 三、双链与标签

- 用 `[[笔记名]]` 建立链接，Quartz 会自动生成反向链接与关系图谱
- 标签用 `#标签` 或 frontmatter 的 `tags`
- 命名建议：**领域前缀**，如 `人工智能/医疗AI`

## 四、目录约定

```
content/
  科技/ 金融/ 医疗/ 人工智能/     # 四大主线
  daily/arxiv|policy|markets|trending  # 自动情报（勿手动改）
  templates/                     # 模板（不发布）
  private/                       # 本地私有，自动忽略发布
```

## 五、同步与发布

```bash
git add .
git commit -m "笔记：xxx"
git push
```

GitHub Actions 自动构建，约 1 分钟后在 Pages 生效。

## 六、不发布的内容

- frontmatter 里 `draft: true`
- 放在 `content/private/` 目录（已在 `ignorePatterns`）
- 放在 `content/templates/` 目录

## 七、每日情报

四个定时任务自动写入 `content/daily/` 并 commit。想改抓取关键词，
直接编辑 `scripts/fetch_*.py` 里顶部的常量即可。

## 八、备份

仓库即备份。建议再加一层：定期 `git clone --mirror` 到移动硬盘或第二个远端。
